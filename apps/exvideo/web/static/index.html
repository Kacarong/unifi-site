🎬 ex-video

강의 영상 → 전사 + 슬라이드 텍스트 + 슬라이드/그림 이미지 → 붙여넣기용 프롬프트(bundle.md)

유튜브는 비공개가 아니면 됩니다(일부 공개도 가능). 구글드라이브는 "링크가 있는 모든 사용자" 권한이어야 합니다. 영상은 720p 까지만 받습니다 — 전사와 슬라이드 글자에는 충분하고 원본 화질로 받으면 수백 MB 가 됩니다. 첫 실행은 모델 다운로드로 시간이 걸릴 수 있어요.
