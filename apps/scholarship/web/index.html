정부·지자체·재단 장학금을 내 조건으로 걸러 봅니다. ☆ 를 눌러 관심 표시하면 마감이 다가올 때, 그리고 다음 모집이 올라올 때 디스코드로 알려 드립니다.

내 조건

부산이라고 적으면 부산 장학금과 전국 대상 장학금만 나옵니다. 구까지 적으면 (예: 부산, 해운대구) 다른 구 전용 장학금도 빠집니다. 어느 지역 것인지 알 수 없는 읍·면 장학금은 빼고, "내 조건만"을 끄면 지역 확인 필요로 보입니다. 지원 내용에 금액만 적히고 용도가 없는 장학금이 많습니다. 그런 것까지 보려면 지원 용도를 "등록금 전용만 빼기"로 고르세요. 소득·성적 기준은 공고마다 적는 방식이 달라 거르지 않습니다. 원문에서 확인하세요.

공고 게시판 출처

한국장학재단 자료(월 1회 CSV + 실시간 포털)와 드림스폰 모집중 목록에 더해 아래 게시판을 6시간마다 읽습니다. '장학' 글을 열어 본문에서 신청 기간을 읽고, 없으면 첨부 공고문(HWP·PDF·ZIP)을 내려받아 읽습니다. 학교·학과·재단 게시판의 목록 화면 주소를 붙여 넣으면 출처를 더할 수 있습니다 (게시판에서 '장학'으로 검색한 화면 주소면 더 좋습니다). 인스타그램·페이스북은 로그인이 필요해 읽을 수 없습니다.

디스코드 알림

봇 토큰은 디스코드 개발자 포털 → 내 앱 → Bot → Reset Token으로 받습니다. 봇을 서버에 초대하고 그 채널에 채널 보기·메시지 보내기·링크 첨부 권한을 주세요. 채널 ID는 디스코드 설정 → 고급 → 개발자 모드를 켠 뒤 채널을 우클릭 → 채널 ID 복사로 얻습니다. 알림은 밤 10시~아침 8시에는 보내지 않고 아침에 모아서 보냅니다.
