# CGV 선점 에이전트 (로컬 PC)

통합 사이트는 **감시와 알림**만 합니다. CGV 로그인 세션이 필요한 **좌석 선점**은
크롬이 설치된 내 PC에서 이 에이전트가 처리합니다.

```
[통합 사이트 서버]  CGV API 폴링 → 취소표 감지 → 디스코드 알림
        │                                   └─ 선점 작업(job) 큐에 적재
        │  (에이전트가 3초마다 가져감)
        ▼
[내 PC 에이전트]   크롬 실행 → 녹화된 예매 흐름 재생 → 좌석 선점 → 결제창에서 정지
```

## 준비

1. 파이썬 3.10+ 과 크롬 설치
2. 의존성 설치
   ```
   pip install -r requirements.txt
   playwright install chromium
   ```
3. **녹화 파일(recipe.json)** 준비 — 최초 1회만.
   원본 [cgv-macro](https://github.com/Kacarong/cgv-macro) GUI(`run_app.bat`)를 실행해
   `녹화 시작하기` → CGV 로그인 → 예매를 좌석 선택·결제하기까지 클릭 → `녹화끝(저장)`.
   저장 위치: `%APPDATA%\CGV-Ticket-Watcher\recipe.json`

## 실행

```
python agent.py --server http://192.168.10.9:8000
```

통합 사이트 설정에서 **에이전트 토큰**을 지정했다면 함께 넘깁니다.

```
python agent.py --server http://192.168.10.9:8000 --token 내토큰
```

실행해 두면 웹의 `CGV 좌석 감시 → 감시 상태` 에 "로컬 에이전트 연결됨" 으로 표시됩니다.

## 동작

- 웹에서 **지금 선점** 버튼을 누르거나, 감시 대상에 **자동 선점**을 켜 두면 작업이 생깁니다.
- 에이전트가 작업을 가져가면 크롬 창이 열리고, 녹화된 흐름대로 좌석을 잡은 뒤
  **결제 수단 선택 화면에서 멈춥니다.** 실제 결제는 직접 하세요.
- 진행 상황과 결과는 웹의 `선점 작업` 목록에 실시간으로 표시됩니다.

## 참고

`cgv_macro/` 폴더는 원본 cgv-macro 패키지 그대로입니다. CGV UI 가 바뀌면
`cgv_macro/replayer.py` 의 셀렉터만 고치면 됩니다.
